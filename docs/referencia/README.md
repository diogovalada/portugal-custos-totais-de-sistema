# Material de referência

Estes documentos são as notas de planeamento e de investigação de dados produzidas antes da reorientação do projeto (agosto de 2026). **Não são canónicos.** O desenho em vigor está no [PROTOCOLO.md](../../PROTOCOLO.md) e o calendário no [ROTEIRO.md](../../ROTEIRO.md).

Continuam úteis como fonte de pistas: onde estão os dados, que licenças têm, que lacunas existem e que armadilhas contabilísticas evitar. Os factos aqui registados têm data de agosto de 2026 e podem estar desatualizados. Por exemplo, Almaraz foi entretanto prolongada até 8-6-2030 pela Orden TED/864/2026. Antes de usar qualquer número, confirme-o na fonte original.
