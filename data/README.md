# Dados do modelo

Este diretório fica reservado a inputs e transformações do modelo:

- `raw/`: aquisições que podem ser redistribuídas ou instruções de download;
- `interim/`: transformações intermédias;
- `processed/`: inputs canónicos prontos para o modelo;
- `manifests/`: proveniência, licenças, schemas e checksums.

Metadados de investigação vivem em `registers/`, não aqui. Nenhum dado raw sem licença clara deve ser adicionado ao Git.
